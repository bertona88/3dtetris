# 3D Blocks

Prototipo mobile-first di un puzzle 3D di blocchi cadenti, con Tetris citato come antenato storico del gameplay e un'identita visiva indipendente. I pezzi cadono in una griglia tridimensionale e possono essere controllati con trascinamento e swipe.

## Funzioni

- tre proiezioni ortogonali: fronte, alto e lato
- swipe sullo sfondo per cambiare vista
- trascinamento del pezzo nella griglia
- rotazione e caduta rapida
- livelli, punteggio, cancellazione degli strati e riavvio
- controlli touch e interfaccia responsive per cellulare

## Avvio locale

```bash
npm ci
npm run dev
```

Apri l'indirizzo indicato dal server di sviluppo.

## Build

```bash
npm run build
```

Versione online: https://3dblocks.wofi.ai
